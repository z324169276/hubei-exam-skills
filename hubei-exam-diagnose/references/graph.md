# 知识点依赖图谱

## 维护说明

- 边写错会让诊断把根源指错方向，改边前请确认是否符合实际教学顺序。
- 新增知识点时，至少连一条入边或出边，避免图里出现孤立节点（孤立节点只能被单独测出薄弱，无法回溯）。
- 强度建议：强依赖（不懂前件就学不会后件）0.85–0.95；中等（有帮助但不必须）0.65–0.8；弱关联（同领域语义相关）0.5–0.6。
